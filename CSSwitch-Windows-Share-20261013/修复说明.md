# CSSwitch Windows 2026-10-17 修复版

本次直接替换原分享目录中的安装包。原下载地址保持可用，文件名中的 `20261013` 仅用于链接兼容；整包版本为 `0.8.4-winshare.20261017`，安装器版本为 `0.8.4.1017`。旧版本可从 Git 历史获取。

## 解决的问题

原 Windows 设置窗口关闭后仅隐藏，WebView2 继续驻留。在本机排查中，释放 CSSwitch 界面后 Edge 音频及网站播放恢复。本次将设置窗口改为按需创建、关闭时销毁，后台服务独立保留；再次打开设置时重建窗口。

同时处理原生窗口创建失败后的重试、关闭过程中再次打开的请求，并保留显式退出和重启时的后台清理。动态设置窗口沿用原有本地权限；其他平台的窗口策略不变。没有关闭 Edge 音频沙盒或端口身份校验。

## 升级方法

保存设置及 Science 中未完成的工作，在 CSSwitch 内选择“退出 CSSwitch”，待后台退出后运行安装器，选择原分享版安装目录。右上角 × 只关闭设置界面，后台仍在运行。安装器拒绝正在使用的目录或不属于此分享包的非空目录。重新打开后若提示旧 listener 占端口，先正常退出旧实例，不要绕过身份保护。

设置窗口销毁会丢弃未保存的界面输入；已保存配置保留。完整步骤见 [先看这里.txt](先看这里.txt)。
