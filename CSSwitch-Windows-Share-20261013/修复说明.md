# CSSwitch Windows 2026-10-20 依赖修复

## 已确认的原因

此前分享包包含 VC++ 与 WebView2 依赖，但缺少启动脚本使用的 Git Bash。桌面程序支持 `CSSWITCH_GIT_BASH`，原分享启动器未设置它；目标电脑没有系统 Git 时可能在沙箱启动脚本阶段失败并回滚。这与另一台电脑提供的 2026-10-19 修复记录一致。

此结论来自对分享启动器、打包清单及脚本调用代码的核对；没有访问另一台电脑，也没有独立读取其原始 operation.log。对方记录写明尚未验证完整 Science 启动，因此不能将那份记录当成端到端成功证据。

## 本次变更

- 版本 `0.8.4-winshare.20261020`，安装器 `0.8.4.1020`。
- 内置官方 PortableGit `v2.56.0.windows.2` 的完整私有依赖，保留原始许可证与工具库。下载 SHA-256 已与 Git for Windows 官方发布接口核对，见 `git-runtime-source.json`。
- 启动器先检查私有 Bash 及必需工具，再向桌面子进程传入 `CSSWITCH_GIT_BASH`。使用 `bin/bash.exe`，保证桌面清理子进程环境后仍能找到私有工具。
- 依赖检查在清理后的环境中执行，不读取用户 shell 启动文件，不依赖系统 Git 或修改系统 PATH；检查失败时在启动前直接提示。
- 保持正常启动与 `--start` 的语义，正常启动不会继承旧的自动启动标记。
- 附带 Science-Companion 1.2.2，包含对话文件右键、PDF 预览外部打开与沙箱中文提示修复。
- 基于已发布的 2026-10-17 安装器重新打包。`desktop.exe`、`csswitch-gateway.exe` 和全部 5 个脚本逐字节保留，因此原有窗口关闭/WebView2 释放修复仍在。
- 不修改 Claude Science 程序，不复制其 Conda/runtime、账号配置、SSH 私钥或研究数据。

## 使用

在 CSSwitch 中明确选择“退出 CSSwitch”，然后运行同目录的 `CSSwitch-0.8.4-Windows-x64-20261013-Setup.exe`，选择原分享版目录覆盖安装。从桌面/开始菜单快捷方式重新启动，避免直接运行 `desktop.exe`。插件需要自行运行安装脚本并在 Edge 重新加载。完整步骤见 `先看这里.txt`。

本次直接替换 GitHub 原分享目录中的安装器，保留旧目录和文件名以兼容原下载链接；内容为 2026-10-20 依赖修复版。原安装器可从 Git 历史获取。

当前启动器源码见 `CSSwitch-Launcher.cs`；保留的 `csswitch-panel-repair.patch` 是 2026-10-17 窗口生命周期修复补丁，其对应 desktop.exe 已在本包中保留。
