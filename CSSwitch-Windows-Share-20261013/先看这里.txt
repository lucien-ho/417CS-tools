CSSwitch Windows 分享包 — 2026-10-20 依赖修复版

版本：0.8.4-winshare.20261020；安装器 0.8.4.1020；附带 Science-Companion 1.2.2。
为保留原下载链接，仓库目录和安装器文件名仍含 20261013；文件内容已替换为 2026-10-20 依赖修复版。

本次修复：
- 安装包内置官方 PortableGit 2.56.0.windows.2，补齐启动脚本需要的 Git Bash 和工具。
- 启动器先检查依赖，再通过 CSSWITCH_GIT_BASH 将私有 Bash 路径传给桌面程序。
- 不要求目标电脑预先安装 Git，不修改系统 PATH。runtime\git 与 Science 的 Conda/runtime 无关。
- 保留 2026-10-17 的窗口关闭及 WebView2 释放修复；desktop.exe、gateway 和启动脚本字节不变。
- 中文插件升级到 1.2.2，支持对话文件右键、PDF 预览外部打开及 Windows 沙箱提示中文。

安装与更新：
1. 保存设置，在 CSSwitch 左下角选择“退出 CSSwitch”。仅关闭窗口会保留后台。
2. 运行 CSSwitch-0.8.4-Windows-x64-20261013-Setup.exe，选择原分享版目录覆盖安装，或选择空目录。
3. 从桌面或开始菜单的 CSSwitch 快捷方式启动。请使用 CSSwitch-Launcher.exe 入口，避免直接运行 desktop.exe。
4. 首次使用需另行安装官方 Claude Science，填写自己的服务地址、API key 和模型。
5. 需要中文和外部打开时，运行安装目录 Science-Companion\Install-or-Update.cmd；到 edge://extensions 重新加载扩展，再刷新 Science。首次加载选择 extension 子目录。

说明：
- 安装目录中的 runtime\git 请随程序保留。若检查提示缺失，请重新安装完整包。
- CSSwitch-Launcher.exe --diagnose 输出 gitBashReady 等依赖状态，不会启动 Science；--check-git 通过时返回 0。
- 完整退出前请勿覆盖安装。安装器不接管身份不明的进程，不绕过 8765/预览端口保护。
- 旧电脑上的单独修复启动器不再是必需项；新启动器直接完成依赖检查，无需多层转发。
